# 《古醫今鋒》

## 📖 專案說明
都市奇幻 × 懸疑冒險 × 醫術專業長篇小說
字數目標：10 萬字以上
語言：繁體中文
風格：輕正劇基調、成熟情感線、醫道與懸疑交織

## 📂 結構
- `chapters/`：各章 Markdown 檔案
- `OUTLINE_V2.md`：完整 70 章結構大綱與力量體系對照
- `CHARACTERS.md`：角色設定與關係演進表
- `GITHUB-PUSH-GUIDE.md`：上傳流程說明

## 📝 寫作原則
- 每章約 1,500～2,000 字，節奏：1 正義事件＋1 情感推進＋1 能力突破
- 親密關係以「信任累積→危機共渡→情感交付」為主，避免直白描寫
- 古醫術設定：《五經歸元術》，四境遞進，每次突破伴隨代價
- 懸疑引擎：古醫傳承來源 × 醫療黑幕 × 反派理念，三線交錯
